☁️ Configura Cloud Sync

Connetti TradoCroods a Firebase per sincronizzare i dati su tutti i tuoi dispositivi. È gratuito!

1. Vai su console.firebase.google.com e crea un nuovo progetto (es. tradocroods)
2. Nel progetto clicca Aggiungi app → scegli </> Web → registra l'app
3. Vai in Build → Realtime Database → crea database → scegli Test mode
4. Vai in Build → Storage → inizializza → scegli Test mode
5. Torna in Impostazioni progetto e copia la configurazione qui sotto:
